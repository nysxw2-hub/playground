# 金月軒線上訂單：Google 試算表 + Apps Script

網站送出的訂單會寫進 Google 試算表，同時寄 Email 通知店家。
在 `index.html` 填入 `ORDER_API_URL` 之前，網站維持**示範模式**，不會送出任何資料。

```
網站結帳 ──POST──▶ Apps Script 網頁應用程式 (doPost)
                     ├─ 檢查資料、依「商品」工作表重新計價
                     ├─ 寫入「訂單」「訂單明細」
                     └─ 寄新訂單通知信
```

## 一、部署（約 10 分鐘，只需做一次）

1. **建立試算表**：到 Google 雲端硬碟新增一份 Google 試算表，命名為「金月軒訂單」。
2. **貼上程式**：在試算表點「擴充功能 → Apps Script」。
   - 把編輯器裡預設的程式碼全部刪掉，貼上本資料夾的 `Code.gs`，按儲存。
   - （建議）點左側齒輪「專案設定」，勾選「在編輯器中顯示 appsscript.json」，回到編輯器把 `appsscript.json` 的內容換成本資料夾的版本。這樣時區會固定為台北，部署設定也會預先填好。
3. **初始化**：上方函式選單選 `setup`，按「執行」。
   - 第一次會要求授權：選你的帳號 →「進階」→「前往（不安全）」→「允許」。這是因為這支程式是你自己寫的，還沒有經過 Google 審核，屬於正常現象。
   - 回到試算表，會看到「訂單」「訂單明細」「商品」「設定」「每日統計」五個工作表，上方也多了「金月軒」選單。
4. **檢查設定**：打開「設定」工作表，確認「通知信箱」是要收訂單通知的信箱（預設是你自己的）。
5. **部署成網頁應用程式**：在 Apps Script 編輯器右上角點「部署 → 新增部署作業」。
   - 類型選「網頁應用程式」。
   - 執行身分：**我**。
   - 誰可以存取：**所有人**。
   - 按「部署」，複製「網頁應用程式網址」（結尾是 `/exec`）。
6. **接上網站**：把網址貼到 `index.html` 的 `const ORDER_API_URL='';` 引號中間，或直接把網址交給 Claude 處理。
7. **測試**：在試算表選「金月軒 → 模擬一筆測試訂單」，再到網站實際下一筆單，確認試算表有新增資料、信箱有收到通知。

### 如果 Apps Script 是從 script.google.com 直接建立的

也可以用。程式沒有綁定在試算表上時，第一次執行 `setup` 或收到第一筆訂單，會自動在你的雲端硬碟建立一份「金月軒訂單」試算表。
- 試算表網址會印在 Apps Script 的「執行記錄」裡，也可以直接在雲端硬碟搜尋「金月軒訂單」。
- 這種情況下試算表上方**不會**有「金月軒」選單。統計、測試信等功能，請在 Apps Script 編輯器選對應的函式（`reportToday`、`sendTestEmail`、`installDailyTrigger`…）按「執行」。

## 二、日常使用

| 想做的事 | 怎麼做 |
| --- | --- |
| 處理訂單 | 在「訂單」工作表的「狀態」欄用下拉選單切換：新訂單 → 製作中 → 可取餐 → 已完成（或已取消）。整列會依狀態變色，「狀態更新時間」也會自動記錄 |
| 改價格 | 直接改「商品」工作表的「單價」，網站下單時會用新價格計算 |
| 商品售完 | 取消勾選「商品」工作表的「上架」 |
| 暫停接單 | 取消勾選「設定」工作表的「接單中」；顧客送出時會看到「暫停接單訊息」 |
| 看營收 | 「金月軒 → 產生今日統計」，結果寫在「每日統計」 |
| 每晚自動統計 | 「金月軒 → 安裝每晚自動統計（22:00）」，每晚寄一封統計信 |
| 確認通知信 | 「金月軒 → 寄送測試通知信」 |

> 網站上的商品名稱、價格與圖片寫在 `index.html` 的 `PRODUCTS`。如果在試算表改了價格，記得也同步修改網站，顧客才會看到一樣的價格（實際金額一律以試算表為準）。

## 三、修改程式碼後要重新發佈

在 Apps Script 改了 `Code.gs` 之後，網站**不會**自動套用。請到「部署 → 管理部署作業 → 編輯（鉛筆）→ 版本：新版本 → 部署」。這樣網址不會改變，網站也不用跟著修改。

## 四、安全與限制

- **價格無法被竄改**：總金額一律由 Apps Script 依「商品」工作表計算，不採用網頁送來的金額。
- **防重複下單**：每次結帳帶一組隨機編號，網路重試時不會產生兩張訂單；送出按鈕在處理中會停用。
- **防灌單**：同一支電話 10 分鐘內最多 5 筆、全站 10 分鐘內最多 120 筆，另有機器人陷阱欄位。
- **防公式注入**：以 `=`、`+`、`-`、`@` 開頭的文字會被當成純文字存入，不會在試算表中被執行。
- 網頁應用程式網址會出現在網頁原始碼裡，任何人都看得到，以上防護就是為此設計的。
- 一般 Gmail 帳號每天最多寄 100 封信（Google Workspace 帳號為 1500 封）。超過時訂單仍會寫入試算表，只是不會寄通知信。
- 每筆訂單通常需要 1–3 秒處理。

## 五、檔案

- `Code.gs`：Apps Script 主程式
- `appsscript.json`：專案設定（時區、網頁應用程式權限）
