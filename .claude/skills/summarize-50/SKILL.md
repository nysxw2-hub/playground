# 50 字重點精簡

把使用者提供的文字濃縮成 **50 字以內** 的一段重點。

## 步驟

1. **找出核心**：先讀完全文，回答三個問題——
   - 這段文字主要在說什麼（主題/結論）？
   - 最關鍵的事實、數字、日期、人名或行動是什麼？
   - 讀者看完需要知道或做什麼？
2. **取捨**：只保留上述答案。刪除例子、背景鋪陳、客套話、重複說法、形容詞堆疊。
3. **撰寫**：寫成一句或兩句通順的話，結論放最前面。
4. **計數檢查**：計算字數（中文字、英文單字、數字各算 1 字，標點不計）。超過 50 字就再刪減，直到 ≤ 50 字。內容太短不需硬湊到 50 字。

## 規則

- 使用 **繁體中文** 輸出，除非使用者要求其他語言。
- 忠於原文：不加入原文沒有的資訊、推測或評論。
- 保留關鍵數字、日期、專有名詞，不可改錯。
- 原文若有多個重點，挑最重要的 1–3 個，用「；」分隔。
- 若使用者一次給多段文字，每段各自輸出一則 50 字重點。
- 若原文本身已少於 50 字，直接說明「原文已夠精簡」並附上微調後版本。

## 輸出格式

```
【50字重點】
<摘要內容>

（共 N 字）
```

## 範例

**輸入：**
> 本公司將於下週三（12/3）下午兩點在三樓大會議室舉行年度績效檢討會議，請各部門主管務必出席，並於下週一前將部門年度成果簡報上傳至共享雲端資料夾，以便會前彙整。如有無法出席者，請提前向人資部請假並指派代理人。

**輸出：**
```
【50字重點】
12/3下午兩點三樓開年度績效會，主管須出席；週一前上傳成果簡報，缺席需向人資請假並派代理人。

（共 44 字）
```
